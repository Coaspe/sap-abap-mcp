# 2.0.0 릴리즈 준비 — 2026-10-08

이 문서는 원본 작업 공간의 로컬 준비 및 설치 검증 기록이다. 공개 배포는 별도 승인과 해당 커밋의 GitHub CI 통과 후 수행한다. npm 2.0.0을 게시하지 않았다. GitHub CI 상태는 검토 PR에서 별도로 확인한다.

## 완료한 수정과 검증

- 기존 문서 호출의 HTML 응답을 유지하고, 명시적인 format=text 호출에 4,000자 페이지 및 변경 감지·연속 읽기를 제공한다. 이전 합성 문서 측정의 첫 응답 추정 토큰 감소 약 82.7%는 실제 모델 전체 사용량 또는 청구 금액 절감의 증명이 아니다.
- SAP Cloud SDK 4.9.1 및 기존 인증서 지원을 유지한다. node-forge/sprintf-js는 출처와 변경 범위를 기록한 자체 백포트를 사용한다. Mermaid core와 브라우저 출력은 공식 KaTeX 0.18.2를 사용한다. 부모 SDK/ADT와 패치 의존성을 함께 묶어 설치 스크립트를 실행하지 않아도 소비자에게 같은 코드가 제공된다.
- 원본에서 Node 20.20.2, 22.23.3, 24.11.1의 회귀 테스트 709개가 각각 통과했다(Windows 전용 검사 1개는 macOS에서 제외). Node 20의 병렬 검사에서 2초 CLI 오류 검사 제한이 한 번 만료됐다. 단독 재현을 확인하고 5초로 조정한 뒤 전체가 통과했다. 요구하는 오류 메시지는 그대로 검사한다.
- 패치 전 보안 재현 5개가 실패하고 패치 후 5개가 통과했다. Forge upstream 테스트 837개 통과(기존 pending 4개), sprintf upstream 테스트 28개 통과. 숫자 포맷의 유효한 0자리 동작과 PKCS12 인증서 변환도 유지한다.
- production audit 0개, registry signature 검증, 원래 소스 버전의 OSV 검사 통과. private fork 이름만으로 취약점을 숨기지 않도록 새 권고 및 기존 권고 변경을 출시 게이트에서 거부한다. 자체 백포트이며 공식 upstream 출시 또는 독립 보안 감사로 표현하지 않는다.
- 시작 검사 5개 모드, MCPB/LobeHub manifest, 워크플로·공개 계약·토큰·배치·조건부 배치·탐색 검사 통과. 빈 소비자 설치에서도 보안 동작·실행 파일 해시·시작·출시 계약·audit를 검사한다.
- MCPB는 원본에서 빌드와 고립된 첫 실행/기존 프로필/설정 재열기 검사를 통과했다. 새 renderer asset이 포함된다. 브라우저에서 일반·시퀀스·수식 다이어그램 3개와 화살표 문법을 쓰는 5종의 파서를 확인했다.

## GitHub 보안 검사와 Windows 실행

CodeQL이 발견한 실제 문자열·쿠키 처리 문제는 원본 소스에 수정했다. Mermaid 화살표 Lexer 6건은 HTML 필터가 아닌 문법 토큰이라는 근거를 확인하고 개별 오탐으로 처리했다. 검사 규칙이나 vendor 범위를 제외하지 않았다. 상세 근거는 [CodeQL triage](codeql-release-triage-2026-10-08.md)에 있다.

Windows 전역 npm shim은 셸을 거치지 않고 실제 JS·native 실행 파일로 해석한다. 사용자 경로의 공백·한글·따옴표·퍼센트·명령 연산자를 인수 그대로 전달하는 Windows CI를 추가했다. 해당 최종 커밋의 통과 여부는 PR #29에서 확인한다.

## 프로필 검사 범위

출시용 계약은 10개 이름과 Resource 3개를 모두 요구하며 읽기 8개에는 readOnlyHint=true, 실행 2개에는 false를 요구한다. 실행 기능을 optional로 만들어 통과시키지 않았다. 명령은 npm run conformance:release다.

기존 공개 profile/v1 제안과 npm run conformance:v1은 보존했다. 이 제안은 응용 테스트를 읽기 전용으로 요구하는 오류 때문에 현재 서버를 거부한다. 새 출시 계약의 통과를 기존 제안 통과나 SAP 표준 승인으로 보고하지 않는다. 커뮤니티 규격 검토는 별도다.

## 배포 전 확인

정확한 소스 커밋의 GitHub CI와 준비한 패키지의 설치 검증을 확인하고, 사용자 승인 후 GitHub 릴리즈 및 npm publication을 수행한다. 공개 npm 버전·무결성·git head·실제 공개 설치 검증은 게시 후 수행한다. 로컬 준비가 공개 배포 완료를 뜻하지 않는다.

SAP 변경, SAP 프로그램·ABAP Unit 실행 및 사용자 프로필·자격 증명 변경은 수행하지 않았다. 실제 SAP/BTP 및 Windows 클라우드 수용 여부는 새 버전으로 직접 검증한 상태가 아니다.
