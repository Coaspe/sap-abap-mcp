# Security Policy

## Supported versions

Only the latest stable version published as `@coaspe/sap-abap-mcp` on npm receives security updates.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Coaspe/sap-abap-mcp/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

We aim to acknowledge a report within three business days. Please allow time for coordinated disclosure until a fix is available.

Do not include SAP credentials, SAP URLs, usernames, cookies, tokens, source code, transport contents, business data, or customer-identifying screenshots in a report. Use synthetic or redacted reproduction details instead.

Include the affected package version, the security impact, and the smallest reproducible example that does not contain customer data.
